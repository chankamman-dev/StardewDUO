# 剧情资料与模组列表

App 0.11.1-dev.11（code51，包含 dev.9 优化），兼容配套模组 0.10.1-dev.11。新增用途筛选与本机置顶，见 [按用途查找](FILTERS.md)。

任务 → 剧情事件支持按标题、地点和编号搜索。无作者标题的事件，以关联居民及地点生成摘要，详情明确标注摘要来源；不会编造剧情名称或剧情内容。中文地点和居民名使用当前目录资料。隐藏未知信息开启时，未看过的事件显示“未发现剧情”，可按显示出的地点或编号查找，点入后明确选择查看资料。

能识别的原版时间、好感、婚姻、年份、天气、季节、日期和前置事件条件显示为中文说明。带引号且含斜杠的事件编号保持完整；无法可靠解析的转义或截断语法保持未知。未知的模组条件标记为尚未完整解释，原始资料折叠保存。“可触发候选”仅从已有快照排除部分已知条件不符的事件；不调用原生条件函数，不保证可触发，不触发剧情、不修改存档。

模组管理每页显示 12 项；搜索和筛选作用于全部已加载模组。展开某项、加载预览图和连接状态改变，只更新变化的卡片。未变化的字体画布和预览图片继续复用，离开设置子页后停止模组列表请求；离开某张卡片时取消尚未完成的预览读取。中文备注、本机预览、断线缓存、下屏设置及上屏 GMCM 入口保持可用。

电脑已检查真实目录重放、中英显示、全列表翻页/搜索、预览与备注、设置草稿/保存/冲突、导航和触控反馈。实机长期性能和第三方设置写入验收仍未完成。
