# 测试版验收

先备份存档，记录 App、模组、游戏、SMAPI、Cinderbox 和设备版本。首次安装与覆盖升级分开测试。

## Thor 首次安装

2026-09-27 已完成 beta.1 首次导入、重启保留、无效包拒绝、配对及部分实机短测，范围与未完成项见 [Thor 实机记录](THOR-BETA1-20260927.md)。以下仍作为完整验收步骤。

1. 安装公开 APK；桌面名称为 StardewDS。未导入素材时应出现像素风导入引导页（三步说明、中英切换）。
2. 选择自己的完整素材包：标题、中文/英文、图标、日历和物品目录可显示；关闭 App 重开后素材仍可用。
3. 用缺少文件或损坏的 ZIP 尝试导入：引导页（或“设置 → 本机文件”）行内显示原因，不出现系统 Toast，原素材仍保留。取消文件选择后按钮恢复可用。
4. 启动配套游戏模组并载入存档，检查下屏同步、切出/切回、游戏退出和重连。
5. 在“设置 → 本机文件”导入自己的配对文件，该行显示“已配对”。未配对不能写入；导入后可在允许的游戏状态下操作。

## 实际游玩

- 背包：点按与长按反馈、滚动不误高亮、切页不留反馈、分组、整理、丢弃与垃圾桶、品质价格和物品属性。
- 任务：接告示、收集类原版进度与持有数量的区分、完成后领奖、完成记录、重复点击不重复支付。
- 制作：说明、缺料红色、视图切换、减/加/最大次数、上屏菜单限制。
- 地图和居民：世界/局部图、头像重叠、搜索与视图切换、聊天送礼、今日行程、节日期间对话。
- 农务：采集进度、浇水/机器/动物待办、收获日历、换季和再生作物、利润计算。
- 角色与手册：装备与技能、详情返回、收藏、Wiki在两块屏幕打开及返回。
- 新模组适配：隐藏未知信息与切换存档、模组技能、图鉴与捐赠、家庭和居民关系、上屏 GMCM 设置。手册中的剧情事件默认隐藏未看过的剧情；筛选、明确展开条件、分页及返回应正常。收集包应保留任选材料、品质、金币和未知捐赠状态；Joja 路线应显示相应提示。
- 情境：普通/大箱子整组搬运、商店、钓鱼、矿层、夜晚出货和早晨简报；逐项关闭自动切页。

至少连续游玩 60 分钟，反复滚动、切页及暂停恢复；比较刚启动和运行后的触摸延迟、音效、温度及崩溃。保存前后确认游戏自身存档可正常打开。以上需要实际设备记录；PC 模拟或构建成功不能替代。

查看图鉴、事件、收集包和模组清单后离开页面，相关目录请求应停止。事件的条件只读自模组解析结果；没有执行条件判断，不把这份列表当作“现在可触发”的确认。收集包页只显示进度，不提交捐赠或领取奖励。

## 开发者本机检查

本轮浏览器/原生游戏回归与持续运行范围见 RELEASE.md；GitHub工作流仅已提供配置，未冒充云端运行成功。公开发行文件的校验和见 SHA256SUMS.txt。
