# 按用途查找

App 0.11.1-dev.11（code51），兼容配套模组 0.10.1-dev.11。

任务 → 剧情事件：保留“全部／已看过／未看过”，增加“可触发候选”。类型下拉框可选关系事件、当前地点、未禁用或已禁用，能与状态和搜索同时使用。关系事件按好感、订婚与婚姻条件分类，不猜测未提供的剧情内容。

“可触发候选”是帮助规划路线的初筛：排除看过、禁用，以及已有快照能确认时间、日期、单一季节、年份、好感、背包空位或前置事件不符的事件。至少有一项已知条件可以核对才纳入。尚未解释的条件明确显示“候选 · 待核对”；地点天气、人物可见性、婚姻与附加模组条件不当作已通过。未知事件编号不等于未看过；过期快照不参与判断。它不保证到达地点后一定触发，也不会调用游戏／其他模组的条件检查或触发方法。

设置 → 模组管理：按全部、已置顶、可设置、下屏适配筛选，再按地图扩展、居民故事、剧情事件、农场玩法、技能与收集、外观与光影、声音、前置框架、辅助功能或其他模组筛选用途。分类来自内置的 ID 对应辨认资料，未分类模组保留在“其他模组”；不按名字猜用途。

每张卡片右侧图钉可置顶／取消置顶。置顶模组在各筛选结果前面，仍须符合搜索和用途条件。“已置顶”可单独查看。置顶仅保存在下屏本机，重开 App 保留，不改变 SMAPI 加载顺序、模组文件或配置。

居民：生日季节筛选改为全部、恋爱对象、已结识、今日可送礼、今日未聊天。恋爱资格优先使用当前游戏目录的 datable 标记，支持新增居民及修改原版居民的模组；没有运行时资料时使用离线档案。今日筛选只使用新鲜的已结识居民状态，不把未知状态当作未完成。送礼排除当天已送礼和已达本周额度的居民，配偶按每日规则处理。

这些筛选支持中文、英文，并保留切页前的搜索与筛选。事件按有意义的条件变化更新；模组仍保持每页最多 12 张卡片，未变化的卡片和字体画布继续复用。

当前通过电脑受控回归与真实目录重放。原生剧情触发结果和 Thor 长期使用仍需实机核对，尚未公开发布。
