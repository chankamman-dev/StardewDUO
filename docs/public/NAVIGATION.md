# 页面导航与地图名称

App 0.11.1-dev.8 中，剧情查询在“任务 → 剧情事件”。手册继续提供物品、制作、角色、图鉴、收集包和 Wiki。

“设置 → 模组管理”打开独立子页面，左上返回按钮逐层返回。侧边栏切换主页面后，回到同一主页面会保留刚才的子页面、搜索、详情和滚动位置；更换存档或重新启动 App 后重新开始浏览。模组设置的未保存草稿在离开编辑器时丢弃，返回后重新读取游戏中的设置。

中文地图区域显示星露谷、姜岛、绯红荒地、寓言礁、格兰普顿郊区、高地、山脊村与东斯卡普。显示别名不改变地图内部 ID，不影响坐标与防剧透筛选。未知扩展地区继续使用作者的名称。

本轮已完成电脑中英界面与导航回归；真实大模组组合仍待在 Thor 进入游戏后验收。
