# 隐藏未知信息

设置中的“隐藏未知信息”默认收起，点击标题展开。右侧数字显示已开启的类别数量。六项可以分别设置：

- 未结识居民：隐藏姓名、头像和资料，地图上不显示；生日日历遵循游戏原有显示规则。
- 未发现物品：手册和收集包的未知物品显示剪影和“???”。
- 未发现送礼喜好：直接显示游戏已发现的喜好，其余需点击展开。
- 未解锁地图：地图选择列表不显示未解锁区域。
- 未看过剧情：未看过的剧情资料先收起，点击可单次展开。
- 未收集图鉴：图鉴中未收集的条目显示剪影和“???”，独立于物品手册设置。

“全部隐藏”控制六项。部分开启时点击会全部开启，全部开启时点击会全部关闭。设置只保存在下屏 App，不修改游戏或第三方模组的数据。切换页面保留当前展开状态，重新打开 App 默认收起。

升级时原“开启”迁移为六项全部开启，原“关闭”迁移为全部关闭。之后各项选择独立保存。游戏标记为永远不出现在社交页的角色仍不列入居民页；无可靠发现进度时维持原有兜底行为，不猜测是否发现。关闭居民隐藏不会关闭物品、地图或喜好隐藏。
