# 0.11.1-dev.6 开发测试候选

App **0.11.1-dev.6 / code46**，配套模组 **0.10.1-dev.10**。本候选补完手册中的剧情事件（T9）与社区中心收集包（T10），沿用 dev.5 的运行时目录、防剧透、模组技能、图鉴、家庭与居民关系、农务扩展及模组管理。

- 剧情事件：中英文筛选、搜索、每屏最多 24 项、详情与返回。未看过的剧情默认隐藏，单个事件可明确展开。只显示 MH Events List 解析的条件，不调用触发判断或执行剧情。
- 收集包：运行时房间、完成进度、任选材料、数量、品质、金币和奖励。未知捐赠状态明确保留；Joja 路线单独显示。本页不执行捐赠或领奖。
- 数据请求：切页、后台或暂停会停止需求并取消分页读取；新存档拒绝旧响应；同版目录复用缓存，其他农务数据更新不重建目录。农务前台仍约三秒续期，离开后停止。
- 手册目录的七个入口使用紧凑行高，均可在首屏显示。

本轮通过公开自包含检查，以及 12 组浏览器回归：事件/收集包、防剧透、图鉴、技能、农务扩展、居民关系、模组管理、原有手册、居民视图、触摸反馈、移动视口及农务。新两页留存 16 张中英文截图。事件使用受控契约夹具；收集包以隔离 PC 原生回复为基线。这些检查不代表 Thor 上真实大模组组合、GMCM 菜单或长时间性能已验收。
