# 剧情对白预览

剧情列表优先使用作者提供的事件标题。没有标题时，如果 Events List 1.2.0 已载入的剧情脚本含有可读取的对白，下屏会用“说话者＋对白摘录”辨认事件；详情最多展示三句对白。这是原文摘录，不是作者标题或自动编造的剧情概要。

“隐藏未知信息”开启时，尚未看过的事件继续隐藏这些内容；可以在详情中主动展开。没有可读取对白的事件仍显示居民／地点，并明确提示资料不足。未解析的翻译键、分支控制文本、超限或格式异常脚本不会当作剧情内容展示。

模组只读取 Events List 已有的数据，不执行剧情指令、触发条件、刷新函数或游戏素材加载。预览按事件对象及脚本文本缓存，沿用原有按需、分帧采集和目录容量限制；旧版下屏可以忽略新增字段，新版下屏也可以显示没有对白字段的旧目录。

本轮同时将图鉴“鱼类”换为原版金枪鱼图标，“观鸟”换为本项目绘制的像素鸟。设置中的“情境页”默认收起，点标题可展开；现有开关选项与保存方式保持一致。
